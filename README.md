# PasteMemo

剪贴板历史管理工具，自动记录你复制的文字和图片，随时查找和复用。

## 功能

- 自动记录每次复制（Ctrl+C）的文字和图片
- 卡片列表展示，最新的在最上面
- 搜索文字内容
- 置顶常用记录
- 点击卡片即可再次粘贴
- 可设置 1/3/5 天保留期限
- 后台静默运行，Alt+V 呼出面板

## 用法

**直接运行**

双击 `release/win-unpacked/PasteMemo.exe` 启动。

**开发模式**

```bash
npm run dev:renderer   # 终端 1：启动开发服务器
npm start              # 终端 2：启动应用
```

## 操作

| 操作 | 方式 |
|------|------|
| 呼出面板 | 按 Alt+V 或点击托盘图标 |
| 搜索 | 顶部搜索框输入关键词 |
| 复制 | 点击卡片即复制到剪贴板，然后 Ctrl+V 粘贴 |
| 置顶 | 鼠标悬停卡片 → 点 📌 |
| 删除 | 鼠标悬停卡片 → 点 🗑 |
| 设置 | 点右上角 ⚙ → 选择保留天数 |
| 退出 | 托盘图标右键 → 退出 |
